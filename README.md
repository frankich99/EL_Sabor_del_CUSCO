# El Sabor del Cusco 🍽️🏔️

> **Sistema Web para la Gestión de Pedidos de Comida Local en Cusco**  
> *Proyecto de Laboratorio 1 - Ingeniería de Software (UNSAAC)*

---

## 📌 Descripción del Proyecto
**El Sabor del Cusco** es una plataforma web desarrollada para una startup tecnológica en la ciudad del Cusco, orientada a digitalizar y optimizar la gestión de pedidos de comida tradicional y gastronomía local. 

Conecta a restaurantes típicos, picanterías y emprendedores culinarios cusqueños con comensales locales y turistas, facilitando la ordenación en línea, el control de inventario de platos y el seguimiento de pedidos en tiempo real.

---

## 🚀 Características Principales
- **Catálogo Gastronómico Local:** Visualización interactiva de platos típicos (Chiri Uchu, Lechón Cusqueño, Kapchi de Setas, Trucha frita, etc.).
- **Gestión de Pedidos en Línea:** Carrito de compras intuitivo y confirmación de pedidos.
- **Panel para Restaurantes:** Control y actualización del estado del pedido (Pendiente, En Preparación, En Camino, Entregado).
- **Control de Versiones y Trazabilidad:** Código organizado y gestionado desde el inicio bajo buenas prácticas de Git y GitHub.

---

## 🛠️ Tecnologías Previstas
- **Control de Versiones:** Git & GitHub
- **Frontend:** HTML5, CSS3, JavaScript (React / Vanilla JS)
- **Backend:** Node.js / Express o Python (FastAPI)
- **Base de Datos:** PostgreSQL / MongoDB
